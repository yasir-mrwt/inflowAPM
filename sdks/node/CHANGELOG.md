# Changelog

All notable changes to `@inflowapm/node` will be documented in this file. The project follows [Semantic Versioning](https://semver.org/).

## 0.1.0 - 2026-09-11

### Added

- A typed, fail-open telemetry client with bounded memory and batch-size limits.
- Automatic interval and threshold delivery with bounded retry and full jitter.
- Explicit flush and graceful shutdown APIs with no SDK-owned process handlers.
- Express 4.18+ and Express 5 instrumentation with normalized routes and privacy-safe defaults.
- ESM, CommonJS, and TypeScript declaration outputs from one public entry point.
- Real backend integration coverage, packed-consumer checks, open-handle checks, and request-path benchmarks.
- Node 24 and Node 26 release verification, a guarded npm trusted-publishing workflow, and an exact-commit one-time initial publish path for `0.1.0`.
- MIT package licensing and confirmed `@inflowapm/node` release metadata.
- Implementation-matched quickstart, configuration, reliability, privacy, localhost, self-hosting, and troubleshooting documentation.

No npm release has been published yet.
