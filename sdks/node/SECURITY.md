# Security Policy

## Supported versions

`@inflowapm/node` is published on npm. Security fixes are supported for the current `0.1.x` release line.

| Version | Supported |
| --- | --- |
| Unreleased source | Best effort |

## Reporting a vulnerability

Please report suspected vulnerabilities through a [private GitHub security advisory](https://github.com/yasir-mrwt/inflowAPM/security/advisories/new). Do not open a public issue or include API keys, access tokens, raw telemetry, or other secrets in a report.

Include the affected SDK version or commit, runtime version, a minimal reproduction, impact, and any suggested mitigation. Maintainers should acknowledge receipt privately, investigate before public disclosure, and coordinate a fixed release and advisory when the report is confirmed.
